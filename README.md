# 🎬 Bitdrix

**Cliente de torrents multiplataforma con streaming integrado, creado en Flutter.**  
Bitdrix es una aplicación moderna para Android, iPhone, iPad y Web que permite buscar, añadir y reproducir torrents fácilmente, con una interfaz limpia y una experiencia fluida.

---

## 🚀 Características principales

- 📁 Añadir archivos `.torrent` o enlaces magnéticos.
- 🌐 Buscar y descargar torrents desde webs como [dontorrent.group](https://dontorrent.group).
- ⏬ Descarga progresiva y gestión de torrents.
- 🎥 Reproducción automática en streaming (video/audio).
- 📲 Disponible para Android, iOS, iPadOS y Flutter Web.
- 📦 Código abierto y estructura modular para contribuir fácilmente.

---

## 🧱 Tecnologías utilizadas

- **Flutter** – UI multiplataforma moderna.
- **Dart** – Lógica de negocio.
- **jlibtorrent** (Android) / `libtorrent` (iOS) – Gestión de torrents a nivel nativo.
- **Platform Channels** – Comunicación entre Flutter y código nativo.
- **HTTP + Web Scraping** – Descarga de torrents desde sitios web.
- **Video Player** – Streaming de archivos descargados parcialmente.
